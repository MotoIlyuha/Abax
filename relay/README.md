# Ретранслятор совместной работы

Облачный сервер, через который гости подключаются к автору доски из любой сети. Логика комнаты
(права, склейка проекта, лимит редакторов) остаётся у автора в приложении (`electron/room.cjs`);
ретранслятор только пересылает сообщения между автором и гостями, следит за лимитами и ждёт автора
после обрыва связи. Содержимое досок он не разбирает и не хранит, комнаты живут только в памяти.

```
автор (Abax) ──wss /host──┐                ┌──wss /g/<комната>── гость (браузер)
                          ├── ретранслятор ┤
                          │                └──wss /g/<комната>── гость
```

Протокол описан в начале [`protocol.cjs`](protocol.cjs). Коротко:

- автор подключается к `/host` и отправляет `{ t: 'open', proto }`; в ответ получает идентификатор
  комнаты (128 бит) и токен для возвращения после обрыва;
- гость подключается к `/g/<комната>`; автор получает `{ t: 'join', conn }`;
- данные между автором и ретранслятором идут бинарными кадрами `[флаги][conn][содержимое]`, гость
  получает и отправляет содержимое как есть;
- если связь с автором оборвалась, комната ждёт его `RELAY_HOST_GRACE_MS` (по умолчанию минуту):
  гости остаются подключёнными и получают `{ t: 'relay', event: 'host-away' }`, новых гостей не пускают.

## Развёртывание на VPS

Нужны сервер с Docker и домен. Подойдёт самый маленький: 1 ядро, 1 ГБ памяти, 10 ГБ диска.
Ретранслятор в простое занимает 50–80 МБ, Caddy — 30–40 МБ. На сервере с 1 ГБ добавьте подкачку
на 1–2 ГБ и уменьшите `RELAY_MAX_BUFFER` (образец — в `.env.example`).

Своего домена нет — подойдёт адрес вида `203-0-113-7.sslip.io` (цифры — IP сервера через дефис):
он сам указывает на этот IP, и Caddy получит для него сертификат.

1. Создайте у регистратора домена A-запись (и AAAA, если у сервера есть IPv6), которая указывает
   на сервер, например `relay.example.com`.
2. Откройте на сервере порты 80 и 443: 80 нужен Caddy, чтобы получить сертификат Let's Encrypt.
3. Поставьте Docker с плагином compose: <https://docs.docker.com/engine/install/>.
4. Скачайте репозиторий и настройте ретранслятор:

   ```bash
   git clone https://github.com/MotoIlyuha/Abax.git
   ```

   ```bash
   cd Abax/relay && cp .env.example .env
   ```

   В `.env` укажите свой домен в `RELAY_DOMAIN`. `RELAY_ALLOWED_ORIGINS` — адрес, с которого гости
   открывают доску (GitHub Pages); оставьте пустым, чтобы не проверять.
5. Запустите:

   ```bash
   docker compose up -d --build
   ```

6. Проверьте: `https://<домен>/health` отвечает `ok`.

Обновление — те же команды после `git pull`:

```bash
git pull && docker compose up -d --build
```

При перезапуске комнаты теряются: приложение автора не сможет вернуться в старую комнату
(код 4404) и откроет новую — ссылку для гостей нужно будет отправить заново.

## Настройки

Переменные окружения (в `docker-compose.yml` часть уже прокинута из `.env`; остальные добавьте в
секцию `environment` сервиса `relay`).

| Переменная | По умолчанию | Что задаёт |
| --- | --- | --- |
| `PORT`, `HOST` | `8080`, `0.0.0.0` | где слушать |
| `RELAY_TRUST_PROXY` | выкл. | `1` — брать адрес клиента из `X-Forwarded-For` (крайний правый). Включайте только за своим прокси: в compose он включён для Caddy |
| `RELAY_ALLOWED_ORIGINS` | пусто | через запятую: страницы, с которых пускать гостей. Автора (приложение) не касается |
| `RELAY_MAX_MESSAGE` | 32 МиБ | предел одного сообщения. Пока проект пересылается целиком вместе с картинками, меньший предел оборвёт большие доски |
| `RELAY_MAX_GUESTS` | 30 | гостей в комнате |
| `RELAY_MAX_ROOMS` | 1000 | комнат на сервере |
| `RELAY_HOST_GRACE_MS` | 60000 | сколько комната ждёт автора после обрыва |
| `RELAY_PING_MS` | 20000 | период проверки живости соединений |
| `RELAY_MAX_BUFFER` | 64 МиБ | очередь на отправку одному участнику; кто не успевает принимать — отключается (4408) |
| `RELAY_ROOMS_PER_MIN` | 10 | новых комнат в минуту с одного адреса |
| `RELAY_JOINS_PER_MIN` | 60 | подключений гостей в минуту с одного адреса |
| `RELAY_MAX_CONN_PER_IP` | 200 | одновременных соединений с одного адреса (класс за одним NAT — это десятки) |
| `RELAY_GUEST_MSGS_PER_SEC` | 100 | сообщений в секунду от гостя (курсор — 25); лишние отбрасываются |
| `RELAY_STATS_INTERVAL_MS` | 300000 | как часто писать в журнал счётчики комнат и гостей; `0` — не писать |

Лимиты по адресу для IPv6 считаются по сети /64.

## Коды закрытия соединений

| Код | Кому | Причина |
| --- | --- | --- |
| 4400 | автору | первое сообщение — не `open` или его нет 10 секунд |
| 4401 | автору | возвращение в комнату с неверным токеном |
| 4404 | всем | комнаты нет (не было, закрыта, сервер перезапускался) |
| 4408 | всем | участник не успевает принимать данные |
| 4409 | автору | автор подключился заново, старое соединение заменено |
| 4410 | гостям | комната закрыта: автор завершил работу или не вернулся вовремя |
| 4426 | автору | версия протокола не поддерживается |
| 4429 | всем | слишком много комнат, подключений или соединений с одного адреса |
| 4430 | гостю | в комнате нет мест |
| 4431 | автору | на сервере нет мест для новых комнат |
| 4503 | гостю | автор временно недоступен (комната ждёт его возвращения) |
| любой 4000–4999 | гостю | гостя отключил автор (`kick`); код и причину задаёт приложение, они могут совпадать с кодами выше |

## Приватность

- Сообщения между автором и гостями зашифрованы сквозным шифрованием (AES-256-GCM,
  `electron/room-crypto.cjs`). Ключ создаёт приложение автора и передаёт гостям в якоре ссылки
  (`#…&k=…`), который браузер на серверы не отправляет. Ретранслятор не может прочитать доску,
  подделать сообщение, переслать сообщение одного гостя другому или повторить старое.
- Ретранслятор видит метаданные: IP-адреса участников (без этого не работают лимиты), размеры и
  время сообщений. Он может отбрасывать или задерживать сообщения и повторить подключение гостя —
  тогда у автора в списке появится лишний участник с правами просмотра, без доступа к доске.
- Журнал содержит только запуск, остановку и счётчики (`rooms=… guests=…`), без адресов,
  идентификаторов комнат и содержимого.
- У Caddy журнал запросов не включён: в путях гостей есть идентификаторы комнат.

## Разработка

Из корня репозитория (порт 8080, без лимитов прокси):

```bash
npm run relay
```

Тесты — в `tests/server/relay.test.ts` (запускаются вместе со всеми: `npm test`).
