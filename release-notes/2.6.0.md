## Новое

- **Совместная работа через интернет**: кнопка «Пригласить через интернет» поднимает комнату на облачном ретрансляторе. Гость открывает ссылку на любом устройстве с интернетом — общая сеть Wi-Fi больше не нужна. Сообщения комнаты шифруются сквозным ключом, поэтому ретранслятор видит только зашифрованные данные.
- **Черновики**: страницы, которые видите только вы. Создать черновик — Alt+клик по «Страница +» или долгое нажатие на планшете. Черновики стоят справа от страниц и не попадают ни в проект, ни на диск, ни к гостям совместной работы.
- **Инструмент «Раздвинуть» (S)**: потяните лист вниз за линию нажатия — всё, что ниже, сдвинется и освободит место для новых записей.
- **Общая рамка выделения**: несколько выделенных объектов теперь можно переносить и масштабировать за общую рамку, как один объект.
- **«Открыть в приложении»**: кнопка на сайте запускает установленную Abax по ссылке `abax://`.
- **Веб-версия на сайте**: свежая сборка публикуется по постоянному адресу https://abax-board.website.yandexcloud.net/.

## Улучшено

- Имя участника совместной работы выводится только как текст, для приложения задана политика безопасности содержимого (CSP).
- Входящие сообщения совместной работы проверяются, у протокола появилась версия.
- Поиск по иконкам больше не путается при быстром вводе, панель в узком окне не перекрывается, в меню исправлена подсказка для macOS.
