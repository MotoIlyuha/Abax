# SPEC_CHAT.md — «Чат и уведомления» (ЧУ) и правая боковая панель

Ветка `feat/chat-notifications` (от `feat/avatar-group`, 19.11.2026). Источник решений для всех шагов этой фичи.
Инварианты `AGENTS.md` действуют полностью: без UI-фреймворков, без новых зависимостей, без `innerHTML` для данных
пользователей и сети (только константы кода — SVG-иконки), весь текст интерфейса и комментарии — по-русски,
стили — в `src/style.css`, каркас — в `index.html`.

## 0. Термины

- **ЧУ** — «Чат и уведомления»: кнопка в шапке, режим боковой панели и всё, что с ними связано.
- **Центр уведомлений** — хранилище `src/notify-center.ts` (чистая логика, без DOM).
- **Стопка** — всплывающий виджет уведомлений под кнопкой ЧУ (`src/notify-stack.ts`).
- **Панель** — правая боковая панель с режимами (`src/side-panel.ts`).
- Три режима анимаций доски (см. `src/motion.ts`): «Улучшенные» — пружины (`motionEnabled()`), «Обычные» —
  CSS-переходы (`body.no-motion`), «Выкл» — сразу (`body.no-ui-anim`, `uiAnimOff()`), `prefers-reduced-motion` = «Выкл».
  Компоненты с designbookmark/kokonutui — это «Улучшенные».

## 1. Образцы и как они адаптированы

| Образец | Где у нас | Что берём |
|---|---|---|
| Notification stack (Kokonut UI, MIT) | Стопка под кнопкой ЧУ | Свёрнутая стопка: передняя карточка + 2 выглядывают (PEEK 10 px, scale `1 − 0.05·depth`, содержимое задних гаснет), раскрытие наведением/фокусом (GAP 8), смахивание вбок (DISMISS 100 px, флик 0.11 px/мс, AXIS_LOCK 6, возврат — пружина 520 с критическим затуханием, полёт ≥1400 px/с, ускорение 4200), × на карточке, Delete/Backspace. CSS-режим: `transform/opacity 300ms cubic-bezier(.23,1,.32,1)` |
| Focus mode (designbookmark) | Уход стопки в кнопку ЧУ, «Не беспокоить» | Прилёт карточки: короткое падение −14 px, scale .96→1, прозрачность и размытие 4 px→0 (soft 260/24, fade 420/32). Уход: задние подъезжают под переднюю (`y = k·7`, `scale 1 − k·.05`), через .24 с вся стопка «прячется» в кнопку ЧУ, счётчик перекатывается (roll, fade 420/32) и «подпрыгивает» (×1.18, pop 520/16). Выход из «не беспокоить»/наведение: стопка поднимается из кнопки и раскладывается. Луна в переключателе «Не беспокоить» заливается |
| Tab pill (designbookmark) | «Все / Чат / Уведомления» | Пилюля на двух пружинах по краям: край по ходу движения жёсткий 620/40, отстающий мягкий 170/19 — пилюля тянется к новой вкладке и подбирает хвост. Пилюля тёмная (`--fg`), подпись на ней белая |
| Spring dropdown (уже есть: `src/spring-select.ts`) | Переключатель режимов панели | Добавить к пунктам иконку (константа) и счётчик справа (бейдж непрочитанных у ЧУ) |

Пружины из `tokens.css` образцов уже есть в `:root` (`--spring-soft 260 24`, `--spring-fade 420 32`, `--spring-pop 520 16`,
`--spring-settle 280 22`, `--spring-lead`, `--spring-trail`). Для пилюли вкладок — свои константы 620/40 и 170/19 (как в tabs.js).

## 2. Центр уведомлений — `src/notify-center.ts` (без DOM)

```ts
export type NoticeKind = 'chat' | 'system';
export type NoticeLevel = 'info' | 'ok' | 'warn';
/** Иконка системного события — ключ каталога иконок (SVG — константы кода). */
export type NoticeIcon = 'bell' | 'join' | 'leave' | 'rename' | 'cursor' | 'avatar' | 'role' | 'rights' | 'summon'
  | 'follow' | 'link' | 'offline' | 'online' | 'hidden' | 'draft' | 'remove' | 'image' | 'board';
export interface NoticeUser { userId?: number; name: string; cursorId?: string; avatar?: string | null }
export interface NoticeInput {
  kind?: NoticeKind;            // по умолчанию 'system'
  level?: NoticeLevel;          // по умолчанию 'info'
  title: string;                // имя участника или короткий заголовок
  body?: string;                // текст сообщения или пояснение
  icon?: NoticeIcon;
  user?: NoticeUser;            // для аватара (событие участника, сообщение чата)
  action?: { label: string; run: () => void };
  onClick?: () => void;
  quiet?: boolean;              // отклик на моё действие: в стопке показывается, но сразу прочитано
  chatId?: string;              // сообщение чата, к которому ведёт уведомление
  ts?: number;
}
export interface Notice extends NoticeInput { id: string; kind: NoticeKind; level: NoticeLevel; ts: number; read: boolean }
```

- `pushNotice(input): Notice`, `notices()`, `unreadCount(kind?)`, `markRead(kind?)` (все или одного вида),
  `markNoticeRead(id)`, `clearNotices(kind?)`, `onNotices(fn) → отписка`, `NOTICE_LIMIT = 200` (старые вытесняются).
- «Не беспокоить»: `doNotDisturb()`, `setDoNotDisturb(on)` — хранится в `localStorage['doska.dnd']` (try/catch).
- Счётчик кнопки ЧУ = `unreadCount()` (чат + система, тихие не считаются).
- `showPill()` из `src/activity-pills.ts` остаётся обёрткой совместимости: превращает старые опции в `NoticeInput`
  (`kind`→`level`, `text`→`title`, `cursorId`→`user`). Все ~25 вызовов размечаются: события от других людей и
  системы — обычные; отклик на своё действие («Вы позвали всех…», «Автопереход выключен», «Связь восстановлена») — `quiet`.
  События состава (`showUserEvents`) — структурные: `title` = имя, `body` = «присоединился к доске», `icon`, `user`.

## 3. Кнопка ЧУ — `#btn-notify`

- В `index.html` — в `.topbar-left` **перед** `#btn-share` (сторона `row-reverse` → кнопка правее «Поделиться», крайняя справа).
- Вид: белая плашка 48×48 как `.topbar-group` (тень, радиус шапки), иконка — облачко с точками; видна всегда
  (и без совместной работы). Старая `#btn-chat` в `.collab-group` удаляется.
- Счётчик: пилюля в правом верхнем углу, акцентная, белые цифры (`1…99`, `99+`), смена числа — перекатом
  (`createRoll` из `src/roll-text.ts`) и подпрыгиванием ×1.18 (pop 520/16); 0 — счётчик сжимается и исчезает.
  «Не беспокоить» — счётчик серый, у кнопки маленький полумесяц, подсказка «Не беспокоить включено».
- `aria-label` / `title`: «Чат и уведомления» или «Чат и уведомления: непрочитанных — N»; `aria-expanded` — панель в режиме ЧУ.
- Наведение мышью — стопка показывается снова (если в ней что-то есть); щелчок — панель в режиме ЧУ.
- `src/topbar-fit.ts` учитывает новую кнопку (она не сжимается и не уходит).

## 4. Стопка — `src/notify-stack.ts` (`#notify-stack`, заменяет `#activity-pills`)

- Место: `position: fixed`, правый край — по правому краю кнопки ЧУ, верх — 8 px под шапкой; ширина 340 (на узком — `100vw − 24`).
- В стопке не больше `STACK_MAX = 5` последних уведомлений; 6-е вытесняет самое старое (оно уезжает и гаснет).
- Одна карточка — просто карточка; несколько — свёрнутая стопка (Kokonut). Наведение мышью или фокус — раскрыта
  списком с заголовком «Новые · N» и кнопкой «Скрыть».
- Новое уведомление влетает спереди (Focus mode). `STACK_IDLE_MS = 5000` после последнего нового (и без наведения,
  фокуса, перетаскивания) — стопка уходит в кнопку ЧУ (Focus mode), счётчик перекатывается.
- Наведение на кнопку ЧУ — стопка поднимается из кнопки (в ней — то, что ушло, пока не прочитано или не убрано);
  уход мыши с кнопки и стопки — через 600 мс снова в кнопку.
- Карточка: аватар участника (с его курсором) или цветной квадрат 32 px с иконкой события (info — акцент, ok — зелёный,
  warn — янтарный), заголовок, время («сейчас», «2 мин», «14:02»), текст в 2 строки, необязательная кнопка действия.
  У события участника на аватаре маленький значок события. × — убрать из стопки (уведомление прочитано).
  Щелчок — `onClick` или панель ЧУ на нужной вкладке (чат — к сообщению).
- Открыта панель ЧУ — стопка не показывается (уведомление сразу в ленте); «Не беспокоить» — стопка не показывается,
  уведомление «падает» в кнопку: короткий призрак карточки под кнопкой (только «Улучшенные»), счётчик растёт.
- Тихие уведомления показываются в стопке на 3.5 с и в кнопку не уходят (не копятся).
- Чтение с экрана: скрытая живая область `aria-live="polite"` проговаривает текст нового уведомления.
- Режимы: «Улучшенные» — пружины по образцам; «Обычные» — CSS 300 мс; «Выкл»/reduced motion — сразу.

## 5. Панель — `src/side-panel.ts` (`#side-panel`)

Геометрия (широкий экран ≥ 760 px): `position: fixed; top: 12px; right: 12px; bottom: 12px; width: var(--side-panel-w)`
(360 px), белая, `--shadow-card`, радиус как у окон. Панель накрывает холст (холст не сжимается).
Правая часть шапки (`.topbar-left`) и `#bottombar` уезжают влево на ширину панели + кнопку закрытия
(`--side-panel-shift`, той же пружиной soft 260/24; «Обычные» — CSS 300 мс; «Выкл» — сразу).

- **Кнопка закрытия** `#side-panel-close` — 48×48 **снаружи** панели, слева от неё, верх по верху панели (зазор 8).
  Иконка «свернуть вправо». В режиме ЧУ на её месте стоит сама кнопка ЧУ: при открытии кнопка ЧУ «вливается» в панель —
  («Улучшенные») перелетает пружиной к месту кнопки закрытия, облачко сжимается и поворачивается, крестик раскрывается,
  счётчик перелетает в бейдж переключателя, панель «вырастает» из кнопки (clip-path от угла кнопки), шапка едет влево.
  Закрытие — обратно: панель уходит под кнопку, кнопка пружинит, принимая её (как меню в `menu-motion.ts`).
  «Обычные» — панель выезжает справа с прозрачностью 200 мс, кнопки меняются переходом; «Выкл» — сразу.
- В любом другом режиме кнопка ЧУ снова видна — слева от кнопки закрытия: [аватары][Поделиться][ЧУ][✕]|панель|
  («Улучшенные» — выезжает из-под кнопки закрытия). Щелчок по ней — режим ЧУ (кнопка снова вливается).
- Узкий экран (< 760 px): панель — лист `top: 68px; left/right/bottom: 12px`, кнопка закрытия — в шапке панели справа,
  шапка доски не сдвигается.
- Шапка панели: слева — переключатель режимов (spring dropdown) с иконками; у пункта «Чат и уведомления» справа —
  счётчик непрочитанных (и на самой кнопке переключателя, когда выбран другой режим и есть непрочитанные).
  Справа в шапке — действия режима.
- Режимы (`PanelMode`): `notify` «Чат и уведомления», `history` «История изменений», `help` «Справка»,
  `import` «Импорт», `export` «Экспорт». Каждый — `registerPanelMode({ id, label, icon, mount(host) })`, монтируется
  при первом показе; `mount` возвращает `{ show?, hide?, actions?: HTMLElement }`.
- API: `openSidePanel(mode?)`, `closeSidePanel()`, `toggleSidePanel(mode)`, `sidePanelOpen()`, `sidePanelMode()`,
  `onSidePanel(fn)`. Последний режим и вкладка ЧУ запоминаются в `localStorage['doska.sidePanel']`.
- Esc внутри панели закрывает её (если открыт выпадающий список — сначала его). Фокус: при открытии — в панель
  (в режиме ЧУ — в поле сообщения, если можно писать), при закрытии — на кнопку ЧУ.
- `F1` и кнопка «Помощь» (`#btn-help`) открывают панель в режиме «Справка» (заглушка меню помощи уходит).

## 6. Режим ЧУ — `src/notify-panel.ts`

- Под шапкой — Tab pill: «Все», «Чат», «Уведомления»; у вкладок «Чат» и «Уведомления» — число непрочитанных.
  В шапке справа — переключатель «Не беспокоить» (полумесяц, заливается при включении) и «Прочитать всё».
- **Все** — общая лента по времени: сообщения чата и системные события; разделители дней («Сегодня», «Вчера», «18 ноября»);
  линия «Новые» над первым непрочитанным при открытии. Показ вкладки помечает прочитанным всё.
- **Чат** — только сообщения + поле ввода. Помечает прочитанным чат.
- **Уведомления** — карточки системных событий (как в стопке, но полные) + «Очистить». Помечает прочитанными системные.
- Сообщение чата: чужие — слева, аватар 28 px у первого сообщения группы, над группой имя (цвет плашки курсора) и время;
  пузырь `--surface-sunken`, радиус 16, угол к аватару 6. Свои — справа, пузырь акцентный, белый текст, без аватара.
  Группа — подряд от одного автора в пределах 3 минут (промежуток 2 px, иначе 12 px). Сообщение только из 1–3 эмодзи —
  крупно, без пузыря. Ссылки — `<a target="_blank" rel="noopener noreferrer">` с `textContent`. Время полностью — в `title`.
  Новое сообщение появляется: «Улучшенные» — пружина (подъём 8 px + scale .96→1), «Обычные» — CSS 180 мс, «Выкл» — сразу.
- Системное событие в ленте «Все» — компактная строка по центру: значок/аватар 20 px, текст, время; warn — янтарный оттенок.
- Поле ввода: автоувеличение до 6 строк, Enter — отправить, Shift+Enter — перенос; слева кнопки «Прикрепить изображение»
  и «Прикрепить выделенное»; справа круглая кнопка «Отправить» (активна при тексте или вложении); счётчик после 400 символов.
- Без совместной работы: на «Все»/«Чат» — пустое состояние «Чат появится, когда к доске подключатся участники» и кнопка
  «Поделиться» (открывает окно «Поделиться», только у автора). Читатель — «Читатели не пишут в чат», поля нет.

## 7. Изображения и объекты доски в чате

Протокол (одновременно `src/room-host.ts` и `electron/room.cjs`, одинаковые сценарии тестов; облачная комната — тот же
`room-host.ts`): `{t:'chat', text, att?}`. Текст может быть пустым, если есть вложение.

```ts
export interface ChatImageAtt { kind: 'image'; src: string; w: number; h: number }
export interface ChatBoardAtt {
  kind: 'board'; pageId: string; pageName: string; ids: string[]; count: number;
  preview: string; w: number; h: number;
  /** Копии элементов для «Вставить копию»; нет — только просмотр (слишком велико или копирование запрещено). */
  elements?: unknown[];
}
/** Вложение вытеснено из памяти хаба (бюджет) или страница скрыта для получателя. */
export interface ChatGoneAtt { kind: 'gone'; was: 'image' | 'board' }
export interface ChatHiddenAtt { kind: 'hidden' }
export type ChatAttachment = ChatImageAtt | ChatBoardAtt | ChatGoneAtt | ChatHiddenAtt;
```

Чистые правила — в `src/room-chat.ts` (зеркало для Electron — `electron/room-chat-att.cjs`, тест паритета):
- `CHAT_IMAGE_MAX = 400_000` символов data URL (`data:image/(jpeg|png|webp);base64,…`), `CHAT_PREVIEW_MAX = 200_000`,
  `CHAT_SIDE_MAX = 4096` (w, h — целые 1…4096), `CHAT_BOARD_IDS_MAX = 200`, `CHAT_BOARD_JSON_MAX = 300_000`
  (JSON элементов), `CHAT_ATT_BUDGET = 6_000_000` (всё вложенное в буфере комнаты).
- `cleanChatAttachment(raw, { copy })` → вложение, `undefined` (нет вложения) или `null` (сообщение отклоняется).
  Элементы: массив ≤ `CHAT_BOARD_IDS_MAX` объектов со строковым `type`, **без `task`** (ответы заданий не утекают),
  без поля `by`; JSON ≤ лимита. Без права `copy` (`participantCaps`) — `elements` срезаются, а вложение `board` целиком
  отклоняется: скриншот выделения — тоже копия.
- `trimChatAttachments(list)` — если вложения в буфере превышают бюджет, у самых старых вложение → `{kind:'gone', was}`.
- `chatMessageFor(m, canSeePage)` — снимок на получателя: `board` со страницы, скрытой для получателя, → `{kind:'hidden'}`
  (ни превью, ни элементов, ни названия страницы). И в рассылке, и в истории `init`.
- Клиент получает сообщения только через проверку формы (как `isChatMessage`), элементы перед показом и вставкой —
  через `sanitizeElement` (`src/file.ts`).

Клиент:
- Изображение: кнопка-скрепка (`<input type=file accept="image/*">`), вставка из буфера в поле, перетаскивание на панель.
  `src/chat-image.ts`: уменьшить до 1280 px по длинной стороне, JPEG 0.82 (PNG с прозрачностью — WebP), при превышении
  лимита — ниже качество/размер. До отправки — чип вложения с миниатюрой и ×.
- Выделенное: кнопка «Прикрепить выделенное» в поле ввода и пункт «Отправить в чат» в быстром меню выделения.
  Превью — `renderScene` выделения до 480 px по длинной стороне; элементы — копии без `task`; превышен лимит или
  копирование запрещено — без элементов (только просмотр; при запрете копирования кнопка недоступна, с подсказкой).
- Получатель: картинка — превью в пузыре (щелчок — просмотр поверх доски, Esc закрывает, кнопка «Вставить на доску»);
  объекты — карточка с превью, «N объектов · «Страница»», кнопки «Показать» (перейти на страницу, кадр по объектам, вспышка;
  если их уже нет — «Объекты уже удалены») и «Вставить копию» (только если можно править текущую страницу; через
  `insertCopies` → `pushHistory`, патч проверяет хаб как обычно). `gone` — «Вложение больше недоступно», `hidden` —
  «Объекты со страницы, которая вам недоступна».

## 8. Другие режимы панели

- **История изменений** — `src/history-diff.ts` (чисто): `describeChange(prev, next)` → «Добавлен рисунок», «Удалено 3 объекта»,
  «Перемещено 2 объекта», «Изменён текст», «Изменён стиль»… `state.ts` хранит время каждой записи; список «сделано —
  сейчас — отменено» (отменённые бледнее), щелчок — переход к состоянию (повторные undo/redo), «Отменить»/«Повторить» сверху.
- **Справка** — поиск, «Быстрый старт» (короткие советы), «Горячие клавиши» (из `src/hotkeys.ts`, клавиши — `<kbd>`),
  версия приложения.
- **Импорт** — зона перетаскивания (PDF, изображение, проект `.json`) и кнопки: «Документ PDF», «Изображение»,
