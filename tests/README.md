# Тесты

| Команда | Что проверяет |
| --- | --- |
| `npm test` | unit-тесты (Vitest): геометрия, стереометрия, состояние и история, хранилище, подписи домашней (даты, «3 страницы»), проверка обновлений (версии, файл релиза под платформу, описание релиза), цвета иконки приложения, страницы на холсте (область превью, камеры бесшовного перехода, блокировка ввода), подсказки, настройка панели инструментов, горячие клавиши (сочетания, занятые браузером), клиент совместной работы, сервер `electron/share.cjs`, main-процесс и preload Electron |
| `npm run test:coverage` | то же с отчётом о покрытии (`coverage/`) |
| `npm run test:e2e` | сквозные тесты в Chromium (Playwright): рисование, выделение, камера, ввод масштаба в шапке, надписи в фигурах, оформление текста (начертание, кегль, выравнивание), прозрачность, скругление и рамка картинки, направляющие выравнивания, панели (и анимация их появления), окно «Все настройки» (перетаскивание, группы, скрытие, горячие клавиши; раздел «Горячие клавиши»: переход по номеру страницы, новая страница, предупреждения в браузере; раздел «О проекте»; скрытый раздел «Экспериментальные»: цвета иконки, страницы на холсте с переходом приближением), страницы и проекты (плавающая кнопка страниц, список с превью, анимация перехода; домашняя сеткой и списком, карусель страниц с последней открытой, иконка проекта: эмодзи, поиск, своя картинка), импорт/экспорт, предложение обновиться (ответ GitHub подставляется, в сеть тесты не ходят), сенсорные жесты, режим Electron, окно демонстрации, совместная работа нескольких участников |
| `npm run typecheck:tests` | типы в тестах |
| `npm run test:all` | всё сразу |

Перед первым запуском e2e: `npx playwright install chromium`. Playwright сам собирает приложение
(`vite build`) и поднимает `vite preview` на порту 4173.

## Как устроено

- `tests/unit` — окружение jsdom; canvas и `Path2D` заменены заглушками (`tests/unit/setup.ts`),
  `measureText` считает 0.5em на символ.
- `tests/server` — окружение Node. Модуль `electron` подменяется в кэше CommonJS, поэтому бинарник
  Electron не нужен (`ELECTRON_SKIP_BINARY_DOWNLOAD=1 npm ci` достаточно).
- `e2e/fixtures.ts` — фикстура `board`: открывает доску и читает состояние через отладочный
  `window.__doska`; координаты в хелперах — координаты сцены. Нарисованная фигура сразу выделена,
  и в прямоугольник, эллипс и треугольник буквы идут как надпись — `board.tool()` перед горячей
  клавишей сам жмёт Esc.
- `e2e/host.ts` — «автор» с `doskaAPI`, как в Electron: хранилище и файловые диалоги живут в тесте,
  за `share*` стоит настоящий сервер совместной работы. Гости — отдельные контексты браузера,
  открывающие ссылку-приглашение; клиент им раздаёт сам сервер из `dist/`.
