# Загрузки и обновления

Страница: https://abaxboard.ru/downloads/. Проверка: https://abaxboard.ru/downloads/latest.json. Файлы хранятся в `/var/www/abax-downloads/versions/<версия>/`. Манифест содержит только опубликованные файлы. Встроенная проверка использует манифест Abax начиная с версии, в которую попадут эти изменения; старые сборки продолжают пользоваться GitHub.

## Выпуск

Изменения должны попасть в ветку, из которой запускается `.github/workflows/release.yml`. Actions → release → Run workflow: нужны новая версия в package.json и описание release-notes/<версия>.md. Сначала создаётся релиз GitHub, потом отдельная задача publish-downloads передаёт файлы на VPS. Если публикация не удалась после создания релиза, повторите именно неудавшуюся задачу этого запуска (Re-run failed jobs), не запускайте новый выпуск того же тега. Пока публикация не удалась, сайт и манифест сохраняют предыдущую версию.

Для Android нужны четыре секрета ABAX_KEYSTORE_BASE64, ABAX_KEYSTORE_PASSWORD, ABAX_KEY_ALIAS, ABAX_KEY_PASSWORD с тем же ключом, что у прежней версии. При отсутствии ключа APK не собирается и в манифест не попадает. Перед публикацией CI проверяет подпись через apksigner. Для публикации настроены секреты ABAX_DOWNLOADS_SSH_KEY и ABAX_DOWNLOADS_HOST_KEY. Ключ на VPS ограничен принудительным запуском `/usr/local/lib/abax-download-receive.py` без терминала и пробросов; он не даёт доступ к исходникам, базе и настройкам приложения. Смена ключа хоста требует проверки отпечатка в панели провайдера и обновления секрета HOST_KEY.

## Хранение и откат

Версионные URL постоянные, автоматического удаления нет. Лимит всех версионных файлов - 2 ГиБ. При его достижении приёмник откажет в новом выпуске, сохранив прежний манифест и файлы; оператор должен увеличить лимит или отдельно согласовать вывод старых ссылок из обращения и освободить место. Дополнительно архив при передаче ограничен 450 МиБ. Не удаляйте версии с действующими ссылками. Файлы версии неизменяемы; повторная передача разрешена только с совпадающими SHA-256.

При откате манифеста от root атомарно скопируйте `/var/www/abax-downloads/versions/<версия>/latest.json` во временный файл в `/var/www/abax-downloads/`, затем переименуйте его в `latest.json`; файлы обеих версий сохраняются. Проверьте JSON и все ссылки через HTTPS. Для отката nginx восстановите резервную копию `/etc/nginx/sites-available/abax.before-downloads`, выполните `nginx -t` и `systemctl reload nginx`: маршрут загрузок исчезнет, остальные маршруты доски сохранятся. Для обновления страницы и приёмника используйте `setup-vps.sh`, предварительно подготовив файлы и открытый ключ в `/tmp/abax-download-setup`; конфигурация доски и база не меняются.

Релиз GitHub служит архивной копией. Файлы подписаны ключом Android; Windows-сборка проекта не содержит настройки Authenticode и может вызвать предупреждение Windows. Установка и проверка совместимости на устройствах выполняются вручную.
